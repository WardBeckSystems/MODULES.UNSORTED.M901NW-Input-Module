| **Weight** | 700 grams. The M901NW is a custom M901C input module designed to provide dual stereo line level input facilities for the Renaissance series of radio consoles. The input source selector allows two separate stereo inputs to be connected to the input module. Each input has its own preamplifier, allowing individual gain trimming and common mode balancing of the discrete source inputs. The sensitivity controls are front panel accessible and accommodate input source levels from -10 to +10 dBu. The selected preamplifier output is routed to the module connector for the insertion of optional processing. The cue bus assignment is directed from the insert return to the cue bus to allow pre-VCA monitoring of source material. A direct left and right channel output is provided at the module connector. These direct feeds maybe optionally used for multitrack applications or to feed the console mix-minus system. The module output is also assignable to any or all of four stereo program buses. Two blind auxiliaries (one mono and one stereo) are also built into the M901NW. Both are pre-set to unity gain, and are assignable pre or post fader by appropriate placement of wire jumpers. The auxiliaries can be turned on and off in similar fashion. A blind assignable monophonic post-VCA feed is assignable by a &quot;Berg&quot; jumper to the console mix minus bus. Unitary control of most module functions is also available at the module connector for machine control as well as external control inputs. Outgoing control signals are furnished as open collector paths to control common when activated. Comprehensive internal module logic allows intelligent control of external machines, with all outgoing control signals following module source selection (source A or B). A momentary closure to control common (through an open collector transistor), is provided when the module is turned on or off for both theA orB source. This totals four independent outputs, one start and stop signal for both theA and B module sources. An additional sustained closure to common is provided for both theA and B input sources. This closure is active when the main channel is on, and is provided for external use. These outputs are also internally assignable to one or all of three internal console muting busses. These busses run to the M905 monitor modules in the console system for muting the monitor speakers. The internal buss structure of the console includes a cue control buss. If a module is assigned to this buss, putting the module into cue will activate the auto cue function in the M905A control room monitor module. A separate LED over the channel fader indicates when the channel has been turned on. Both lamps in the ON and OFF pushbuttons are connected to the edge connector for use as external tally indicators. Module control inputs are also configured to activate when a closure to control common is provided. The module can be turned on and off, the cue can be toggled, and the source can be selected between A and B by simply grounding the appropriate module connector pin. Program buss assignment is also possible external to the module. Again, a closure to control common will effect this assignment. to change a previous buss assignment, the electronic latches require clearing before loading them with new buss assignments. A closure to common will also perform this function. External control of the VCA within each module is also brought out to the edge connector. Application of a voltage between 0 and 5 volts DC will bring the attenuator from no external attenuation to full attenuation from the current fader position. This feature can be of benefit for automated cross-fading. The M901NW Stereo Line Input module is packaged ina 1.5&quot; wide x 16.2&quot; high x 6.6&quot; deep space. This module derives its power from the console system bipolar +/-23 volt power supplies. 1) Source &quot;B&quot; Select Depressing this momentary switch (SW2), enables the &quot;B&quot; input source and disables the &quot;A&quot; input source selection (if it was selected). Double pressing the active switch will cancel the selection. 2) Source &quot;A&quot; Select Depressing this momentary switch (SW1), enables the &quot;A&quot; input source and disables the &quot;B&quot; input source selection (if it was selected). Double pressing the active switch will cancel the selection. This source is selected automatically when power is supplied to the module. 3) P3 Select Switch SW14, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 3 stereo buss in the console. 4) P1 Select This electronically latched, momentary switch, (SW12), assigns the stereo audio signal to the program 1 stereo mix buss. This assignment is performed automatically on module power-up. 5) Q This momentary electronic switch assigns the pre-fader signal to the console's stereo cue buss. This provides a pre-fade listen feed for cueing. 6) ON This momentary switch enables the audio feeds to the console mixing busses, and contains an externally accessible amp for machine tally purposes. 7) OFF This switch turns off the audio feeds from the console mixing busses, and contains an externally accessible lamp for machine tally purposes. 8) Main channel fader This 105mm Penny and Giles linear fader controls the main channel voltage controlled amplifiers. 9) LED DS2 Illuminates whenever the channel has been turned on. 10) P2 buss assignment switch Switch SW14, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 2 stereo buss in the console. 11) P4 buss assignment switch Switch SW15, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 4 stereo buss in the console. 12) &quot;A&quot; source left channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the left channel of the &quot;A&quot; source. 13) &quot;A&quot; source right channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the right channel of the &quot;A&quot; source. 14) &quot;B&quot; source left channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the left channel of the &quot;B&quot; source. 15) &quot;B&quot; source right channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the right channel of the &quot;B&quot; source. Input and Preamplifier The Input and preamplifier section of the M901NW is contained on WBS plug on assembly SA14-281. Refer to drawing B14-281-02-001. Source selection is controlled from the main circuit board, Refer to drawing B901-02-006/2. Switches SW1 and SW2 are the electrically interlocked input selector switches. Depressing SW1 generates a negative going pulse at U13 pin 4. This directly sets section A of U14, a dual J-K flip-flop with preset and clear. This pulse also clears section B through CR9. This operation has resulted in the &quot;A&quot; source being selected and cancelling of the &quot;B&quot; source. Conversely, selecting &quot;B&quot; will cancel &quot;A&quot;. An additional operation of the currently selected source will cancel it too. This OFF feature is not normally possible with mechanically inerlocked switches. The active low logic outputs of U14 are coupled to the SA14-281 preamplifier assembly through connector 281P2 pin 1 (for source &quot;B&quot;) and pin 2 for source &quot;A&quot;. The M901NW does not fully utilize all of the functionality of the SA14-281. The mode selection is set for normal stereo on the M901NW main board by R131 and R132. Otherwise, the SA14-281 operates normally. Inserts Two series-connected, unbalanced insert points are made available at P2, pins 12/14 and 11/13, operating at a nominal level of -6 dBu. They allow insertion of ancillary processing equipment into the mixing channel signal path such as a compressor, equalizer or filter. From the insert points, the signal is routed to U1 and U2, two voltage controlled amplifiers (VCA). The insert return is also coupled to the cue bus switch (U11) and a pre-fade summing amplifier comprised of U3 and associated components. |
| **The main channel VCA** | U1 and U2 for left and right respectively, provide the main channel level function. An output class AB amplifier within the feedback loop of the amplifier ensures the bus summing resistors can be fed with consistent amplitude. The control voltage to the VCA is coupled from the control amplifier by R7, R8 and C4 for the left channel VCA and R20, R21 and C10 for the right channel. Unequal level balance between the left and right channel is factory trimmed with R23. Program Outputs The P1 through P4 bus assignments are activated by U5, U6, U7 and U8. These CMOS analog switches are active when the bus has been assigned, the channel is turned on, and the fader is brought up from the infinity (∞) position. Cue Channel The cue signal originates from abridging takeoff at the inputs to the channel VCA. The stereo feed is switched onto the cue busby U11 section Bb and C. U11 is a CMOS analog switch. Aux 1 Aux 1 is a mono auxiliary which can be assigned pre or post by clipping the appropriate jumper on the main circuit board. The pre-VCA mono feed is generated by U3; while the post VCA mono feed is generated by U4 and associated components. The feeds are routed to U9, CMOS analog switch which controls which feed (pre or post VCA) is connected to the bus summing resistor (R89), and bus control switch (U12 section A). The jumper for turning Aux 1 on is enabled, clipping it will turn the auxiliary off. Aux 2 Aux 2 is the stereo auxiliary which can be assigned pre or post VCA by clipping the appropriate jumper on the main circuit assembly. The pre-VCA audio is bridged across the insert return through C54, C55 and U10. The post-VCA audio is likewise coupled to U10 via C56 and C57. U10 acts as a voltage level CMOS analog switch, which selects the pre or post VCA feed to the bus summing resistors (R90 and R91). Analog switch U12 section Band C expresses the audio to the Aux 2 summing bus when the auxiliary has been turned on. Control Logic The control voltages required to operate the solid state switches and the VCA chips is detailed on schematic sheets B901-02-006/2 and B901-02-006/3. Initial Reset Diode CR24, CR26 and CR27 along with C79, C113 and R107 act as the main power on reset circuit. The slow charging of C79 and C113 by R107 holds the reset lines of U17, U14, U22 and U24 long enough to ensure that: 1) The channel is Off. 2) Cue is not selected. 3) P1 is assigned. 4) Source &quot;A&quot; is selected. 5) P2, P3 and P4 are no assigned. Channel On Momentary action of the Channel On Switch, SW4 produces a negative going pulse at U17 pin 2; presetting theA section of U17. Alternately an external ground applied at edge connector P2 pin 43 will produce the same effect. Once the flip-flop is preset, it's output at pin 15 changes from 0 to 1. This enables the bus program switches, the VCA and the channel on open collector control output. Furthermore, Q10 will saturate and illuminate DS2, the channel on indicator. The channel on logic also provides a momentary closure to control common. This is controlled by U19 and associated components. This closure is active for as long as the switch is closed, and is logically routed by the choice of source (A or B). The timer reset bus runs throughout the console and is essentially a &quot;wired or&quot; circuit. Placing jumper link LK4 into position 1-2 will place a reset signal on the bus which will reset the console timer whenever the channel on button is pressed. Channel Off Momentary operation of the channel off switch SW3 or momentary grounding of the external channel off control input at P2-44 will result ina negative going pulse at U17 pin 3 and &quot;clear&quot; theA section of U17. Consequently Q9 will stop conducting, extinguishing DS2, the mute bus outputs are disabled, a pulse to the open collector off transistors is enabled, the buss assignment solid state switches are disabled and the channel VCA's are turned off. The B section of U17 is used to control the solid state CUE switch, U11 section Band C. This flip flop will change state whenever SW5 is activated. Therefore, with each input pulse, the cue channel will alternate between on and off. This state change can be brought about by two different methods: Momentary operation of the Cue switch SW5, or momentary closure of the external Cue control input at P2-41. Cue channel status is indicated by DS15. Cue Off An additional feature ensures that the Cue Channel will always switch off whenever the mixing attenuator is moved into or out of the infinity (∞) position. This control signal is generated by U18 and associated components. The closure (or opening) of the end of travel switch in the mixing attenuator generates a pulse at U18 pin 10 through U15 section Band D. The output produced at pin 4 of U18 will always be negative going. Diode CR28 passes this pulse to U17 pin 8, thereby clearing the B section of U17 and disabling the cue circuit. Module Tally Lamps All of the bus alignment, source selection, and the cue pushbuttons have integral tally lamps. These LED's are run ina current mode, by a constant current source. Two such current sources are present in this module each furnishing approximately 20 mA for the illumination of the LED's. One current source consists of Q40 and R195 through R197. The current is always running through either DS15 or Q38. When Q38 is on, the LED is short-circuited, and is therefore extinguished. Q38 is enabled when buffer transistor Q37 is turned on by a logic 1 (+6 volts) at tag Q at R189. Since all of the LED's are in series, failure of an LED ora transistor open circuit will extinguish all of the LED's on the same current source. Power Supply Decoupling Power Supply Decoupling is provided by Q45 through Q48 and associated components. Transistors Q45 and Q46 act as darlington connected pass transistors for the positive 18 volts power supply. A secondary decoupler for +6 volts consists of U27, a three terminal regulator and R237, R238 and C111. Negative power supply decoupling is comprised of Q47, Q48 and associated components. Resistors R235 and R230 are fusing resistors which protect the module in the event of catastrophic faults.
